            Statistics

            Settings

            Providers live in settings.json in the app data dir; API keys are stored in the OS keyring (session memory when none is available) — never in the settings file or the database. Text is set in the bundled Source Sans 3 (SIL OFL 1.1), falling back to your system font.

            Media store

            Preserved attachments live in the app data dir, content-addressed by SHA-256 and served to the reading pane read-only. Nothing is ever fetched remotely to display media.

            Storage & backup

            A backup is one versioned file with the whole vault: a consistent database snapshot, your settings, and every preserved attachment — each part checksummed. Passwords and API keys are never part of a backup; restored accounts need to be reconnected.
