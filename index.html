              Settings

              Light, dark, or follow the system.

              A native desktop notification when a sync or folder-watch cycle brings new mail; silent while the app window is focused.

              Closing the window hides the app to the tray instead of exiting, so auto-sync, folder watching, and notifications keep working between opens (the tray menu shows, syncs, and quits).

              Launch the app automatically when you log in (OS login-item registration; applied when you save).

              Storage & backup

              A backup is one versioned file with the whole vault: a consistent database snapshot, your settings, and every preserved attachment — each part checksummed. Passwords and API keys are never part of a backup; restored accounts need to be reconnected.

              Previous vaults

              Media store

              Preserved attachments live in the app data dir, content-addressed by SHA-256 and served to the reading pane read-only. Nothing is ever fetched remotely to display media.

              AI assistance

              Values set here override the process environment for the environment fallback (used when no default provider is set); keys are stored in the OS keyring, never in the settings file.

              The local search index runs entirely on this device and feeds Ask's offline matching; updating is incremental, so only new messages are indexed.

              Technical details

              Providers live in settings.json in the app data dir; API keys are stored in the OS keyring (session memory when none is available) — never in the settings file or the database. Text is set in the bundled Source Sans 3 (SIL OFL 1.1), falling back to your system font.
